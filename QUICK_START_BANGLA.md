## 🆘 Common Issues & Solutions

### Issue 1: Analytics কাজ করছে না
```
Solution:
1. Browser console check করুন (F12)
2. GA ID সঠিক আছে কিনা verify করুন
3. Cache clear করুন
4. 24 hours wait করুন (data দেখাতে সময় লাগে)
```

### Issue 2: Google এ site দেখা যাচ্ছে না
```
Solution:
1. Search Console এ sitemap submit করুন
2. "URL Inspection" tool ব্যবহার করুন
3. "Request Indexing" করুন
4. 1-2 weeks patience রাখুন
```

### Issue 3: Website slow মনে হচ্ছে
```
Solution:
1. Images compress করুন (TinyPNG use করুন)
2. Browser cache clear করুন
3. Different network এ test করুন
4. PageSpeed Insights check করুন
```
